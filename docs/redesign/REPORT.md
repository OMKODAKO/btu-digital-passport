# BTU დიზაინი და სტუდენტის/სტაფის გამიჯვნა: ანგარიში

## გაუმჯობესებული გვერდები და კომპონენტები
- **ახალი კომპონენტები:** `AppHeader` (BTU-ს **ოფიციალური ლოგო**, ამოღებული BTU-ს საკუთარი შაბლონიდან `worker/pdf/assets/template.pdf` → `public/brand/`, მუქი ზოლი მაჯენტა ხაზით) და `AdminTabs` (სტაფის განყოფილებები, აქტიური ჩანართი მაჯენტაშია).
- **სტუდენტის შესვლა (`/login`):** ორი სვეტი, მარცხნივ BTU-ს სტილის სათაური და ქართული ტექსტი, მარჯვნივ შესვლის ფორმა. სტაფის ლინკი აქედან ამოღებულია.
- **სტუდენტის პასპორტი (`/dashboard`):** PDF მთავარ სვეტშია, "Download PDF" და "Open in new tab" პირდაპირ მის თავზე. გვერდით არის Passport ID, ვერსია, თარიღები, ვერიფიკაციის კოდი, ავთენტურობა, QR, უნარები და ვერსიების ისტორია. მობილურზე ყველაფერი ერთ სვეტად ლაგდება.
- **სტაფი (`/admin/*`):** ცალკე ზოლი "STAFF" ნიშნით და ჩანართებით Overview / Students / Import problems / Audit log. ცხრილები და სტატისტიკა ერთიან სტილშია.
- **სტაფის შესვლა (`/admin/login`) და ვერიფიკაცია (`/verify`):** იგივე სტილი. ვერიფიკაციის შედეგის სათაური ახლა ჩვეულებრივი, წასაკითხი ტექსტით ჩანს.
- **ფერები:** BTU-ს მაჯენტა (#E6007E) მთავარი ქმედებებისთვის, მუქი ნაცრისფერი ზოლისთვის, თეთრი და ღია ნაცრისფერი შიგთავსისთვის, მუქი ლურჯი მხოლოდ შეტყობინებების აქცენტად. შრიფტები: Oswald (სათაურები), Inter და Noto Sans Georgian (ტექსტი).

## უსაფრთხოება და გამიჯვნა
- სერვერზე უკვე იყო როლების შემოწმება: ცალკე ცხრილები, ცალკე cookie და `requireStaff` ყველა ადმინ გვერდზე და API-ზე. ეს უცვლელია.
- **ახალი: ერთი როლი ერთ ბრაუზერში.** სტუდენტად შესვლა ამ ბრაუზერში სტაფის სესიას ხურავს (სერვერზეც), სტაფად შესვლა კი სტუდენტის სესიას. ასე ერთ ბრაუზერში ორივე სივრცე ერთდროულად ღია აღარ არის.
- სტუდენტის ინტერფეისში სტაფის არცერთი ლინკი ან მონაცემი აღარ ჩანს და პირიქით.
